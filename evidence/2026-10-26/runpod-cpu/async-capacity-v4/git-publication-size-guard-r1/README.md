# New Git blob publication guard

Read-only actual-repository checks refuse the97885962-byte accidental admission duplicate,accept subsequent native manifests and the small comparison publication,and refuse an unknown base. The fixed10MiB maximum applies to added/changed blob paths. Existing history is unchanged. Larger raw evidence belongs in immutable private attachments with full SHA/member inventories and authenticated verification. This guard is publication tooling,not part of the Java application artifact or a new Linux performance result.
