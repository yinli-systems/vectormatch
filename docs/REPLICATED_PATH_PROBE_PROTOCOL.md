# Replicated path decomposition on the existing CPU

This diagnostic uses one existing prepaid CPU host, three Aeron UDP replicas and one independent load JVM. No physical fault-domain claim. Each uses the previously recorded disjoint four-CPU sets, G1, 1–2 GiB heap and four active processors. Leader 0, MTU 1248, SHARED media driver, archive/catalog/consensus sync level 2, capacity-190k-v1 and outbox 524288 remain fixed. No change to matching, accounting, deduplication or production defaults.

The explicit `ReplicatedPathProbeNode` diagnostic entry point shares `ClusterNodeMain` transport construction. NOOP responds with the normal accepted-IOC response length and echoed correlation, but zero business-state sentinels; it performs no command decoding, trading or account processing. MATCHING delegates to the unchanged matching service. Both receive exactly the same encoded IOC fixture and 256 pre-window warmup commands. Normal production startup always selects the matching service. Fresh same-host sync2 state is mandatory for the diagnostic node.

An independent absolute source clock releases every planned original into a nonblocking 256-slot queue; a single network owner has at most 256 outstanding correlations. Full queues record NOT_SENT, transport-accepted missing replies remain UNKNOWN. All originals, including late schedules and failures, are saved. No source CSV or checkpoint force occurs during arrivals; the source stores bounded samples in memory and writes them after the arrival/drain window. A source crash can lose that in-memory measurement tape: this is explicitly a measurement-harness durability difference from R3, **not** a business durability reduction. JFR and process telemetry remain active in every arm. No direct before/after improvement is claimed against the different R3 harness.

Every replica records correlation, session, request size and service callback duration using its own clock; no cross-JVM clock subtraction. Source scheduled-to-confirmed, actual-offer-to-confirmed and release lateness use the source clock. Complete raw frames and CSVs, worker timing, GC/JFR, CPU/IO/pressure metrics, final matching snapshot and same-implementation canonical replay are retained. The matched fixture is bounded single-lot IOC, not the high-rate mixed TCP workload or a continuous retention/export benchmark. All archive bytes are verified before private upload; private download verification precedes duplicate retirement.

Sequence: native functional NOOP and MATCHING at 10/s for 2 seconds; then 30-second 100/s NOOP/MATCHING/NOOP/MATCHING. These first four arms quantify the business addition, not a software optimization. Safety/correctness/identity failure stops the campaign; timing or performance failures are preserved.

Next, a single-factor optimization screen uses MATCHING at 100/s for 60 seconds, explicit replica data-path maximum parks of 1 ms / 100 µs / 1 ms / 100 µs. The existing idle policy configures independent driver/archive/consensus/service instances and leaves the source unchanged. All four run on the same qualified artifact; only the replica park limit differs. Both B arms must accept all originals, have zero unknown/rejection/not-sent, release lateness at most 20 ms, at least 99% confirmations inside the window, p99 at least 10% below their A partner and p99.9 no higher. Otherwise no optimized-policy promotion. CPU cost is separately reported.

After closure and full archive verification, use the selected policy for one uninterrupted 1800-second, 100/s MATCHING window. Retain the 1 ms policy if the paired criterion fails. Report all 30 minute windows, full p50/p99/p99.9 and failures. Registered long gates: all originals accepted, no unknown/not-sent/rejection, source release lateness ≤20 ms, global and every minute p99 ≤25 ms, global p99.9 ≤100 ms and correct final state. Failure remains failure. This rate is deliberate bounded endurance; it does not establish 100K/s or 250K/s replicated capacity. This campaign does not consume or ACK the retained outbox.

Runs have birth-checked owned process identities, deadlines and a 512 MiB disk floor. Stop only owned experiment JVMs, retain the existing CPU. Frozen binaries, source hash, configuration and all qualification results accompany the evidence.
