## Defect reproduced independently

The old sampler reads process state,then reads its command line. A process may exit between those reads. An R→Z transition with an empty command line reproduces the same exception in a deterministic fixture. Linux documents empty command-line contents for zombies;processes can also modify their arguments. See [proc_pid_cmdline](https://man7.org/linux/man-pages/man5/proc_pid_cmdline.5.html). This establishes a sampler defect,not the exact historical C2 trigger,whose PID/read-phase detail is unavailable.

`scripts/owned_process_identity.py` opens one no-follow process directory descriptor,and reads stat→cmdline→stat relative to that descriptor. The two stat records must identify the requested PID and the same positive start time. A documented exited/zombie state or disappearance of that original process instance is absence. A live process with empty,partial or over-budget arguments is refused after at most two1ms retries. Changed birth time,wrong PID,malformed stat,symlink directory and permission failures remain refusals. Errors record PID,phase,state,start time and byte count without disclosing argument contents.

An open proc directory does not prevent PID reuse,but its descriptors do not refer to a newly reused process. See [the Linux proc filesystem contract](https://docs.kernel.org/filesystems/proc.html). This remains a non-atomic observation of a process-controlled argv,not an authentication mechanism or a hard kernel-time guarantee. Owned signals still require the existing exact PID/start/argv comparison and pidfd lifecycle checks. No numeric-PID fallback or forced kill is introduced.
